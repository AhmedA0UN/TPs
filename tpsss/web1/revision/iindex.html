Glossaire des technologies web

HTML
Langage de balisage utilisé pour structurer le contenu des pages web.
CSS
Langage de style permettant de définir l’apparence visuelle des éléments HTML.
JavaScript
Langage de programmation utilisé pour rendre les pages web interactives.
SQL
Langage de requête utilisé pour interagir avec les bases de données relationnelles.
